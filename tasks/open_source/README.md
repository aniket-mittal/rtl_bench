# open_source tasks

Tasks generated by `taskgen/` from the seed designs in `../../sources/`, using the `claude` profile
(every LLM step is a fresh headless Claude Code agent: Sonnet writes bugs, mutants and specs; Haiku answers
specs for validation).

A task is one seed design with one injected bug. The agent gets `spec.md` and must write a module `dut`
that Yosys proves equivalent to `reference.v`.

```
<collection>/<design>/mutant_<k>/
    spec.md        task statement (the valid spec with the lowest validator solve rate)
    reference.v    hidden answer: the mutated design the spec describes
    meta.json      source file, bug type, solve rate, proof strength, other valid specs, original code
index.jsonl        one line per task
raw/               pipeline inputs and outputs (designs.jsonl, skipped.jsonl, *_questions.jsonl, run logs)
```

`difficulty` in `meta.json`/`index.jsonl` is a first cut from the validator's solve rate
(easy >= 0.75, medium >= 0.4, hard < 0.4). Most tasks are easy; classification is still to do.

## Regenerate

```bash
cd taskgen
python prepare_sources.py --out ../tasks/open_source/raw/designs.jsonl \
    basic_verilog verilog-uart verilog-i2c secworks-sha256 secworks-aes serv picorv32 verilog-eval
# set original_designs_path in config.yaml, then
python -W ignore main.py run --profile claude --output ../tasks/open_source/raw/questions.jsonl
python export_tasks.py --designs ../tasks/open_source/raw/designs.jsonl \
    --out ../tasks/open_source ../tasks/open_source/raw/*_questions.jsonl
```

Set `claude_cli_bin` in `config.yaml` if `claude` on your PATH is an old version.
